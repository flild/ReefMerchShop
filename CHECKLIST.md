# Чек-лист перед релизом проекта РИФ

Внимательно пройдитесь по каждому пункту, чтобы убедиться в готовности сайта к запуску в production.

## 1. Переменные окружения (.env)
Обязательно добавьте/обновите следующие ключи в конфигурации вашего сервера или хостинга (Vercel/иной):

- [ ] `NEXT_PUBLIC_SITE_URL` — Актуальный домен (например, `https://reef.studio`). Важно для SEO, генерации Sitemap и правильной работы метаданных OpenGraph/Robots.
- [ ] `NEXT_PUBLIC_YANDEX_METRICA_ID` — ID счетчика Яндекс Метрики. Без этого ключа скрипт аналитики не будет загружен.
- [ ] `NEXT_PUBLIC_GOOGLE_ANALYTICS_ID` — ID счетчика Google Analytics (формата `G-XXXXXXXXXX`).

## 2. SEO и Метаданные (Microdata/JsonLd)
В компоненте `src/components/seo/JsonLd.tsx` указаны заглушки и значения для компании по умолчанию:

- [ ] **Адрес**: Указано "Санкт-Петербург, RU". Если есть более точный адрес (улица, дом), его следует обновить в `OrganizationJsonLd`.
- [ ] **Контактный номер/почта**: Если есть публичный email или телефон (для `contactPoint`), его нужно добавить в JSON-LD разметку для лучшего сниппета в Google.

## 3. Социальные сети и контакты
В компоненте футера `src/components/layout/Footer.tsx` и `Header.tsx` (или других местах):

- [ ] Убедитесь, что ссылки на ВК (`https://vk.com/reef_print`) корректны.
- [ ] Убедитесь, что ссылка на Telegram (`https://t.me/reef_print`) ведет на актуальный канал/чат или менеджера.

## 4. Контент
- [ ] Проверить, что актуальный логотип (`/public/logo.png`) загружен и заменяет placeholder, если тот использовался.
- [ ] Проверить изображение для соц. сетей (`/public/og-image.jpg`), которое будет использоваться при шаринге ссылок на сайт. Оно должно быть хорошего качества и отражать суть вашего проекта.

## 5. Дополнительно
- [ ] Сборка и деплой: Убедитесь, что команда `npm run build` проходит без ошибок.
- [ ] База данных: На production сервере будет другая база (если используется не локальный SQLite). Убедитесь, что у вас настроена Drizzle ORM для продакшн базы и применены миграции `npm run db:push` (или `drizzle-kit migrate`).
