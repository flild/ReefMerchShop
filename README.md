# Reef (РИФ) — Твоя гавань мерча



Современная веб-платформа и система управления для специализированной типографии, ориентированной на художников, иллюстраторов и авторов мерча.

## Технологический стек



* **Фреймворк:** Next.js 15+ (App Router)


* **Язык:** TypeScript (Строгая типизация, без использования `any`)


* **Стилизация:** Tailwind CSS v4 (Семантические переменные, кастомные утилиты)


* **База данных:** SQLite (Локальный файл `local.db` для разработки)


* **ORM:** Drizzle ORM


* **Анимации:** motion/react (Framer Motion)


* **Иконки:** lucide-react



## Основной функционал



* **Витрина и портфолио:** Динамическая галерея готовых работ с разбивкой по категориям и адаптивной сеткой.


* **Каталог материалов:** Актуальное наличие акрила и фурнитуры с автоматическим учетом остатков и порогами уведомлений.


* **Коллекты:** Система совместных закупок мерча для снижения стоимости производства за счет объема.


* **Калькулятор заказов:** Интерактивный расчет стоимости на основе актуальных цен и формул из базы данных.


* **Инструменты авторов:** Генератор мокапов, автоматическая предварительная проверка макетов, динамические чек-листы и хранилище шаблонов.


* **Личный кабинет и заказы:** Отслеживание статуса производства, система загрузки макетов и утверждения цветопроб.


* **Админ-панель:** Полноценное управление ценами, остатками на складе, заказами, пользователями и контентом сайта.



## Архитектура и правила разработки



1. **Разделение компонентов:** По умолчанию используются серверные компоненты (Server Components) для SEO-оптимизации и прямых безопасных запросов к БД. Директива `'use client'` применяется исключительно для интерактивных элементов (хуки состояния, обработчики событий, анимации).


2. **Мутации данных:** Любые изменения в базе данных выполняются строго через Server Actions (`'use server'`). Внешние API-роуты используются только для вебхуков.


3. **Дизайн-система:** Запрещено использование префикса `dark:`. Темизация реализована через глобальные CSS-переменные (`bg-theme-surface`, `text-theme-text`, `text-theme-accent` и т.д.). Интерфейс опирается на классы `.anime-border` и `.anime-shadow` для поддержания единой стилистики.


4. **Файловая система:** Физические файлы (макеты, фото цветопроб) не хранятся в БД. Drizzle управляет только метаданными в таблице `files`, сами файлы направляются в S3-совместимое хранилище.


5. **Типизация:** Исключительно строгая типизация через схемы Drizzle (например, `$inferSelect`). Код должен быть предсказуемым и безопасным.


6. **SEO:** Использование канонических ссылок, микроразметки `JsonLd` (включая хлебные крошки), динамической генерации `Metadata` и семантической HTML-разметки.
